# Orizon CP

Orizon CP is the official deployment control plane for the Orizon ecosystem.

**Important Note:** This is **not** a standalone control plane. It is designed to be deeply integrated with the Orizon platform. Users must first purchase and provision a server through Orizon before they can access and utilize this control plane. 

Once a server is provisioned via Orizon, this control plane automatically handles:
- Automated application deployments and container management
- Integrated database provisioning (PostgreSQL, Redis, MongoDB)
- Automated SSL certificate generation and domain routing
- Environment variables and log management

For more information on purchasing a server, please visit the main Orizon platform.
